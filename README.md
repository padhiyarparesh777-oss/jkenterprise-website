# JK Enterprise & Mahir Mobile Shop — Website

A responsive, static business website with animated particle background, CSS 3D-style orb, glassmorphism cards, scroll reveals and a demo enquiry form.

## Preview locally
Open `index.html` in a browser. For a local dev server, use any static file server.

## Publish free
### Cloudflare Pages
1. Create a GitHub repository and upload these files.
2. In Cloudflare Dashboard, open Workers & Pages → Create → Pages → Connect to Git.
3. Select the repository. Framework preset: None. Build command: leave blank. Build output directory: `/`.
4. Deploy. Cloudflare will provide a `*.pages.dev` address.

### GitHub Pages
1. Push these files to a GitHub repository.
2. Open repository Settings → Pages.
3. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.

## Before publishing
- Add the shop's real phone/WhatsApp number, exact address, opening hours and any confirmed service details.
- The current enquiry form is demo-only; it does not send or store submissions. Connect a trusted form backend or add a configured WhatsApp link before relying on it.
- No prices, warranties, certifications or opening hours have been invented.
- External Google Fonts are optional; the site has fallback fonts.
